2. START THE APP
   --------------
   npx expo start


3. RUN ON DEVICE
   --------------

4. TEST THE APP
   -------------
   - App opens to Practice tab
   - Tap "Start Practice"

   - See simulated results
   - Go to Profile tab to toggle theme

================================================================================
  TROUBLESHOOTING
================================================================================

If npm install fails:
  - Use Command Prompt instead of PowerShell
  - Or fix PowerShell: Set-ExecutionPolicy RemoteSigned

If app won't start:
  - Clear cache: npx expo start -c
  - Reinstall: rm -rf node_modules && npm install

If TTS doesn't work:
  - Test on real device (not web browser)
  - Check device volume
  - Check silent mode (iOS)

If you see "unmatched route":
  - This is now fixed with app/index.tsx
  - Make sure all files are saved
